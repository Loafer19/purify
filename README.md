# Purify - bringing clarity to websites

![Purify](./public/logo.png)

Purify is a browser extension that helps you to focus on the content you are reading by removing all the distractions

## Features

- removes useless elements from the page
- per-site settings pages with toggles for each option
- DaisyUI-themed popup UI with light/dark theme support
- host aliases so the same site works across www, mobile, and alternate domains
- Global mode for cookie banners and newsletter modals on every page
- Custom CSS per site (syncs via Chrome; ~8 KB per site)
- Home shows Global + the current tab’s site first, then all other sites
- configure predefined settings for each site

several sites have already been optimized for a minimalist experience

![settings](./.github/screenshots/settings.jpg)

The popup lists supported sites; open a site to drill down into its options.
